# v1.1 requirement index (waves 1-6)

Every one of the 81 v1.1 IDs (MSG-7..10, BRN-5..17, QRY-13..46, CST-4..10, INT-7..12, ACL-8..10, ARC-6, BEN-9..21) maps to the tests that accept it, or to 'deferred' with the reason. Test names are the proposed acceptance tests of the v1.1 plan (no ID has an Accept line of its own). A name marked *(planned, key)* belongs to a package that is being built in the same wave; the consolidated suite runs it once that package lands. The rationale for every deferral is in docs/architecture.md, 'Scope and remaining work'.

This is the final index after waves 5-6 (person read model, write contract, transcripts, connectors, ops, commitments, disclosure). The v1.0 requirements the matrix also covers (ACL-6 token matrix, ARC-5 purge, CST-6 caches) are named in the notes of the rows they extend.

## Deferred after wave 6

- Recall hard-scope filters on identity_quality and time_precision: the shared scope-function signature (api.scope_filter) is fixed; both are filterable in SQL (api.appearances, api.attribution) and in the result-set filter op.
- Identity state as of a time: person_id and merges are rewritten in place, not replayed, so person functions answer for the current identity state under as_of.
- A real model's quality for media-noise judgement and request extraction: the operations run behind the provider registry; only the deterministic local rules are tested offline.
